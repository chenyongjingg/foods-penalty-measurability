类别定义（点开）
  • FORGED_INSPECTION_REPORT — 伪造/变造检验检测报告：文书事实中出现伪造、变造、买卖检验/检测报告、检验结论、检测数据或检疫证明。
  • TAMPERED_TRACEABILITY — 篡改溯源数据：篡改、伪造或删除溯源码、追溯码、溯源/追溯信息。
  • FAKE_CERTIFICATION — 虚假认证：伪造、变造、冒用、买卖认证证书、认证标志或认证材料。
  • FALSE_LABELING — 标签虚假标注：标签/说明书虚假标注，篡改或虚假标注生产日期，冒用厂名厂址产地等（不含报告、认证类）。
  • UNLICENSED_OPERATION — 无证或超范围经营：未取得许可、无证或超出许可范围从事食品生产经营。
  • OTHER — 其他违规：文书确有食品安全违法行为，但不属于以上五类（如商标侵权、超范围使用添加剂、未履行进货查验等）。
  • UNRESOLVED — 无法判定：文书残缺、事实不足以判断，或同一文书同时构成多种类型且无法确定主类型。
判断顺序 · 四步（必读）
  1. 找事实：定位「经查明 / 经调查 / 现查明 / 经查」之后的段落。
  2. 找依据：找「违反了《…》第…条」与「依据《…》第…条…决定」这两句。
  3. 定主行为：以处罚依据所罚的那个行为为准；只在事实里提过、没被作为处罚依据的行为不算。
  4. 按序匹配，命中即停：检验报告 → 溯源 → 认证 → 标签虚假 → 无证 → 其他 → 无法判定。

五个易错点：

  • 「标签不符合规定」但内容不虚假（未标配料表、格式错误）⇒ 选其他，不是标签虚假标注。
  • 商标侵权 ⇒ 选其他，不是虚假认证。
  • 处罚依据是无证经营条款 ⇒ 选无证，即使事实里提到标签问题。
  • 销售食用农产品不需要食品经营许可。
  • 「涉嫌…」是立案表述，不作判据；以「经查明」的事实为准。
