## 6. 失效模式与恢复手册

| 失效 | 判据 | 恢复 |
|---|---|---|
| daemon 死了 | `pgrep -f "cli daemon"` 为空；kv 日期不前进 | `bash scripts/install_daemon.sh` |
| 采集/标注卡住 | chain 日志长时间无 `done`；`/proc/locks` 有 flock | 查 `logs/pipeline.log` 尾部；**不要 `pkill -f` 裸匹配**（会自杀） |
| vLLM 挂了 | `/v1/models` 连续 3 次失败 | `scripts/start_llm.sh` |
| 锁文件残留 | `state/cycle.lock` 存在 | **不是判据**：filelock 文件常驻，看 `/proc/locks` 或进程表 |
| 终版没出 | `data/reports/finalize_20261105.json` 不存在 | 看 `logs/finalize.out`；先确认 watcher 在跑，再手工跑 `finalize_release.py --stamp 20261105` |
| 同一 UTC 日重复建包 | 导出器 `REFUSED` | 用 `--out` 或次日再建（D-70） |
| pod 重启 | 四个进程全没 | 按序：`start_llm.sh` → `install_daemon.sh` → 代理 → `finalize_watch.sh` |
